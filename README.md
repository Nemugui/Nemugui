## 🔍 Featured Project — Home Network Reconnaissance

As part of Phase 2 networking practice, I conducted a full reconnaissance of my home network using Kali Linux and nmap.

**What I found:**
- Mapped 4 active devices on `192.168.110.0/24`
- Discovered LG Smart TV exposing 8 open ports including HTTP on 8008
- Identified router running **lighttpd** web server with firmware version exposed in banner
- Analyzed DNS performance: Cloudflare (11ms) vs Google (55ms) vs ISP (63ms)
- Performed reverse DNS lookups revealing Google's Manila/Tokyo datacenter infrastructure
